# 智聊 AI 会员与计费说明

本文件说明智聊 AI 的会员等级、价格、额度规则、续费与发票相关事项。

## 一、会员等级

| 等级 | 适用对象 | 主要权益 |
| --- | --- | --- |
| 免费版 | 所有注册用户 | 每日 20 条对话额度，不支持知识库上传 |
| 标准会员 | 个人重度用户 | 每日 500 条额度，可创建 3 个知识库，单次文档不超过 50MB |
| 专业会员 | 专业创作者 | 无限对话额度，知识库不限数量，支持长文档与批量上传 |
| 企业版 | 团队 / 企业 | 按席位计费，含权限管理、审计日志与专属客服 |

## 二、价格（参考）

- 标准会员：29 元 / 月，连续包月 25 元 / 月。
- 专业会员：69 元 / 月，连续包年 588 元 / 年。
- 企业版：按席位 99 元 / 席位 / 月，年付享 8 折，具体以商务合同为准。

## 三、额度规则

1. 一条"对话额度"指一次完整的用户提问与模型回答。
2. 知识库检索本身不消耗对话额度，但生成回答会计入。
3. 额度在每日 0 点（北京时间）重置，未使用部分不累计。

## 四、续费与取消

1. 连续包月 / 包年可在"我的 — 订阅管理"中随时关闭自动续费，关闭后当前周期仍可使用至到期。
2. 到期后会员权益自动降级为免费版，已上传的知识库保留 30 天，逾期将清理。

## 五、发票

付费订单可在"订单与发票"中申请电子发票（增值税普通发票），一般 3 个工作日内开具并发送至预留邮箱。企业版支持开具增值税专用发票，需提供税号与开票资料。
