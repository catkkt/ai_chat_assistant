# 智聊 AI 常见问题（FAQ）

本文件汇总用户在使用智聊 AI 过程中最常遇到的问题与解答，便于快速自查。

## 1. 问答不基于我的文档怎么办？

请确认：（1）文档已成功上传且索引状态为"已完成"；（2）提问内容在文档中确实出现；（3）知识库检索阈值未设置过高导致相关片段被过滤。可在"知识库"页查看已索引的片段数量。

## 2. 回答出现"编造"内容（幻觉）怎么办？

RAG 模式下模型优先依据文档，但若文档未覆盖该问题，模型仍可能补充通用知识。建议：提高相似度阈值、缩小检索范围，或在提示词中明确要求"仅基于知识库回答，未知内容请说明未查到"。

## 3. 上传文档支持哪些格式？

支持 PDF、Word（.docx）、Markdown（.md）、纯文本（.txt）。标准会员单次文件不超过 50MB，专业会员与企业管理大文件。

## 4. 对话额度不够用？

免费版每日 20 条，超出后次日重置；如需更多可升级标准或专业会员。企业版按席位提供充足额度。

## 5. 三端数据是否同步？

Windows、macOS 客户端与 Web 版实时同步对话记录与知识库；移动端 App 上线后也将纳入同步。

## 6. 如何接入自己的系统？

开发者可通过开放 API 与 MCP 协议将智聊 AI 的能力嵌入自有应用，详见开发者文档与控制台中的 API 密钥管理。

## 7. 充值或退款问题？

退款适用条件与流程见《退款政策》；发票申请见《会员与计费》。仍有疑问可联系在线客服或发送邮件至 support@zhiliao.example。
