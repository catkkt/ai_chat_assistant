# 智聊 AI 产品介绍

智聊 AI 是一款面向个人与企业的智能对话客户端，支持多轮对话、文档问答、写作辅助与智能体（Agent）编排。本文件介绍产品的核心功能、适用人群与基础使用方式。

## 一、核心功能

1. **智能对话**：基于大语言模型提供自然语言问答，支持上下文记忆，可连续多轮交流而不丢失主题。
2. **文档问答（RAG）**：用户可上传 PDF、Word、Markdown 等文档，系统会自动切分、向量化并建立知识库，之后所有回答都优先基于用户自有文档，减少模型"凭空编造"。
3. **写作辅助**：支持公文、周报、邮件、创意文案等多种模板，可一键润色、扩写、缩写与改写。
4. **智能体编排**：可将多个专用 Agent 串联，例如"检索 Agent → 总结 Agent → 校验 Agent"，完成复杂任务。

## 二、适用人群

- **个人用户**：用于日常答疑、学习辅助、内容创作。
- **企业团队**：用于内部知识库问答、客服辅助、文档沉淀。
- **开发者**：通过开放 API 与 MCP 协议将智聊 AI 接入自有系统。

## 三、快速开始

1. 注册并登录账号后，在"新建对话"中输入问题即可开始。
2. 如需基于私有资料问答，进入"知识库"页面上传文档，等待索引完成后即可提问。
3. 企业版用户可在"控制台"配置成员权限与计费方式。

## 四、支持的平台

智聊 AI 提供 Windows、macOS 客户端以及 Web 版，三端数据实时同步。移动端 App 预计于下个版本上线。
